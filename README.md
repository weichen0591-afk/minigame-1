# Minigame 1
## Devlog
I would describe Components, GameObjects, and Scenes like making a movie, since I am a film and media major student. Components are like the different skills or jobs a character has. For example, a character can move, make sounds, or react to other objects. These abilities are added through Components. The GameObject is like the character itself, because it holds all of these different abilities together in one place.

The Scene is like the whole movie set where all of the characters and objects come together. Each GameObject has its own Components, but all of the GameObjects work together inside the Scene to create the level. In this way, Components give GameObjects their functions, and GameObjects come together to create the full Scene that the player sees and interacts with.
